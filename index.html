Aplicación de escritorio

El cuaderno digital para trabajar, no para administrar software.

COMPASADO ayuda al profesorado a organizar cursos, registrar calificaciones y calcular resultados respetando la configuración académica que decide cada docente.

Proyecto en preparación de distribución. No sustituye a las aplicaciones oficiales de gestión académica del centro.

Qué permite hacer

Organizar cursos y alumnado

Crear cursos, mantener el listado de alumnos y trabajar con tres evaluaciones por curso.

Configurar cómo se evalúa

Definir pesos de evaluaciones, componentes y actividades según las necesidades reales de cada materia.

Calcular y consultar notas

Obtener resultados de evaluación y curso a partir de las calificaciones y ponderaciones configuradas.

Preparar informes

Exportar informes en PDF para revisar los datos y resultados académicos.

Cómo utiliza Google Drive

COMPASADO emplea Google Drive para conservar la biblioteca privada de cursos asociada a la cuenta que autoriza el acceso. Solicita exclusivamente el permiso drive.appdata, destinado a los datos de la propia aplicación, no a examinar los demás archivos personales de Drive.

Mientras trabajas utiliza copias locales de sesión. La identificación se realiza en el navegador a través de Google: COMPASADO no pide tu contraseña de Google.

El proyecto de desarrollo

COMPASADO es un proyecto personal de desarrollo de software de escritorio, gratuito y sin fines comerciales. Su objetivo es crear una herramienta fiable y mantenible para el trabajo cotidiano del profesorado.

La aplicación está desarrollada en Python y PyQt6, utiliza SQLite para gestionar los datos académicos de cada curso y se integra con Google Drive mediante su API. El desarrollo incluye pruebas automatizadas y preparación de instaladores para Windows y distribuciones Linux.

Pensado para el trabajo del profesorado

Es una aplicación de escritorio cuyo despliegue se ha probado en Windows 10, Windows 11, Debian 13 y Vitalinux 3.5. El responsable TIC puede encargarse de su instalación y el profesor concentrarse en su cuaderno.
